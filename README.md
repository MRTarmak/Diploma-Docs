# Diploma Documentation

This repository contains documentation for a diploma project in Software
Engineering.

The project develops **Flooring Calculator**, a FreeCAD add-on for planning
the layout of rectangular flooring in rooms of arbitrary shape. The add-on
accounts for room geometry, internal obstacles, wall offsets, gaps, and
different layout patterns. It produces a visual layout, material quantities,
cutting templates, and an estimate.

The documentation is written in Typst and includes the technical
specification, requirements, development stages, acceptance criteria, and
documentation requirements.
